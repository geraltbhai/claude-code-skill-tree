Why a tree, not a pile of prompts

Lean context makes every later skill cheaper to run. Fast loops make agent work worth delegating. You feel the savings in order.

Grounded, not guessed

Proposes, then asks

Ten, not two thousand

Every installed skill puts its description into context. A small, sharp set triggers better than a mega-bundle.
